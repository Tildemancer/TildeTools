This addon is for me and my friends serving a suite of modified RP tools to spec.

Bundles modified Chat 2/XIV Messenger/Wordsmith with some edits to serve the main part of this addon, EmoteSplitter-like automatic text splitting in various fields. Also, now there's a Hunspell spellcheck of its own, using Lumina to drag stuff in so that it's much more accurate and less dumb about game names, which is pretty great. Chat 2, XIV Messenger and Wordsmith all use it, and it works in-line now. Yippee!

In theory it should be cross-compatible with the standalone addons and their configs as well, so there shouldn't be any special TildeTools config in its own fancy little box, it should just behave like normal ChatTwo, etc is installed. In case this sucks for later

Also spellchecks the default chat box if you don't want to use Chat 2 or XIV Messenger. Right click a red-underlined word, or hit Insert to correct the one your cursor is in.

Not intended for the public dalamud repos, violates the automation stuff, I think. It may be split for the public repos once this private plugin is feature complete, talked to the lovely folks in the Discord about it earlier and it's honestly very viable, but we're a long way off from that and I'd like to keep it all in one place to see if things break.
